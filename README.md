# Standalone wedding finance homework

Upload index.html, app.js and styles.css to the root of a NEW repository. README.md is optional. This is a complete separate static application. Do not add the old api/, lib/, package.json or vercel.json files.

Open index.html directly in a modern browser, or publish as a static site. If deploying on Vercel: Framework Other, no build command, Output Directory . (repository root). No environment variables are needed. Any site address works; there is no server API or APP_URL.

Select Richard, Anastasia or Jean-Claude to record sales; Kevin to record expenses; Svetlana to approve splits and allocations and view totals. Data is saved in this browser using localStorage and remains after refresh. Each browser and website address has separate records. Clearing site data removes those records. Nothing is imported from or written to any previous project.

No Supabase, Telegram, Sheets, authentication, external APIs, credentials or network integrations. Role selection is only a demonstration: it is not secure isolation from other people using the browser. This version does not satisfy the original assignment requirements for live Telegram/Sheets integrations; it intentionally provides an independent browser-only finance demo.
