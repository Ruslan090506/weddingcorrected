Reviewer instructions: use one Telegram account safely
  1. Open the Telegram bot link above and send /start in a private chat. Copy the numeric user ID from its reply. No bot token is needed.
  2. Select Svetlana and open the workspace. Refresh records, enter your own Telegram ID below and choose an available salesperson. Press Save link. Send /whoami to verify.
  3. Submit a sale through the bot. To submit expenses from the same Telegram account, keep the same numeric ID and choose Kevin below. Save, then send /whoami again. Existing records and original notification chats stay unchanged.
  4. If an employee belongs to another Telegram account, the server refuses the switch. Choose an available employee or coordinate with the other reviewer; never remove someone else's link. Refresh before retrying a stale binding.
  5. Approve the saved items as Svetlana, check return messages in the original chat, and open the Viewer ledger. Retry failed deliveries with the button above. Use unique references; do not delete or seed records to repeat a test.
  6. For Test 2 website decisions, link this same account to Jean-Claude before approving S03 and to Kevin before deciding E04/E05. Keep Test 1 data. Reuse the form for each switch.
